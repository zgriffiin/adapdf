# Adapdf 0.1.0 (pre-release)

Adapdf turns a Word training guide into an accessible PDF (WCAG 2.1 AA and PDF/UA-1)
on your own computer. It has no subscription. This is a pre-release: read "Pre-release:
what is tested and what is not yet confirmed" below before you rely on it.

## What Adapdf does

1. It checks the Word guide for accessibility problems, in plain language, and says
   how to fix each one.
2. It fixes what it safely can, after it asks about each fix. It makes a backup of
   your guide first. It never writes alt text or a title for you.
3. It makes a tagged PDF through your own Word.
4. It checks the PDF with veraPDF (PDF/UA-1).
5. It writes a report (HTML and JSON) next to the PDF. The report is your evidence. A
   person then checks the PDF in PAC and signs off the checklist in the app.

Adapdf does not send your documents anywhere. It works on your computer. Its window
turns off WebView2's background services (WebView2 is the Microsoft component that draws
the window; without this, one test computer saw it connect to a Microsoft address in both default
runs). In 13 test runs of this installer on one computer, no connection to another address
was seen, by a check that samples the connections about once a second and is not a
firewall log.

## Download

Download `Adapdf_0.1.0_x64-setup.exe` from the assets of this release.

The SHA-256 of the file is in `SHA256SUMS.txt`, also in the assets of this release.
To check it, run `Get-FileHash .\Adapdf_0.1.0_x64-setup.exe -Algorithm SHA256` in
PowerShell and compare the value.

The release also has `OpenJDK21U-jdk-sources_21.0.13_9.tar.gz`: the source code of the
Java runtime that the installer includes (its licence, GPLv2, asks for it). You do not
need it to use Adapdf.

The [install guide](https://github.com/zgriffiin/adapdf/blob/v0.1.0/docs/install-guide.md)
tells you how to install and use it. You need no admin rights.

## What you need

- Windows 11, 64-bit.
- Microsoft 365 Word, installed on the computer.
- About 250 MB of free disk space.
- You do not need to install Java or any other program.

## Pre-release: what is tested and what is not yet confirmed

Tested:

- The checks, the fixes, the Word export, the PDF metadata step, the veraPDF run, the
  report and the app have automated tests, and were run with a real Word and a real
  veraPDF on made-up test guides.
- This exact installer file was run on one computer: install, a check and an export
  from the installed copy, uninstall.

Not yet confirmed:

- **PAC has not been run on real guides.** PAC is the checker of record. veraPDF
  passes are not a PAC pass. The first test with 5 real guides (Phase 0 in the
  [product spec](https://github.com/zgriffiin/adapdf/blob/v0.1.0/docs/specs/01-product.md))
  is still to do.
- **The screen-reader walkthrough of the app is not done.** The pages pass automatic
  accessibility checks (axe-core), but a person has not yet used the app with a screen
  reader, high contrast or a magnified window.
- **The install guide has not been tried by a staff user.** A person who did not build
  Adapdf has not yet followed it.
- **One computer, one administrator account.** The installer was not tried on a clean
  computer, on a standard user account, with the city's IT rules (for example
  AppLocker), as an upgrade, or while the app was running.
- **The installer is not signed.** Windows SmartScreen shows "Windows protected your
  PC". If you got the file from the release page of this project, click **More info**,
  then **Run anyway**.

Details are in the [test plan](https://github.com/zgriffiin/adapdf/blob/v0.1.0/docs/test-plan.md).
